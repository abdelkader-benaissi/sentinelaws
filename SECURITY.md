# Security policy

SentinelAWS is an educational lab, not a supported production platform.

Do not report vulnerabilities by opening a public issue. Send a private report
through GitHub's private vulnerability reporting feature after it is enabled
for the repository. Include the affected path, impact, reproduction steps, and
a proposed remediation when available.

Never include AWS account IDs, credentials, Terraform state, secret values,
private IP inventories, or live incident records in a report or commit.
